Follow these steps on your Android TV to enable ADB debugging.

Please scroll down to review all instructions and see the "Don't show again" option.
1. Unlock Developer Options
  • Open Settings on your TV
  • Go to System → About (on Google TV: Device Preferences → About)
  • Scroll down to Build (or Android TV OS build)
  • Click it 7 times until you see "You are now a developer"
2. Enable USB & Network Debugging
  • Go back to Settings → System → Developer options
  • Turn on USB debugging
  • Turn on Network debugging (or ADB over network / Wireless debugging)
3. Find your TV's IP Address
  • Open Settings → Network & Internet → select your active connection
  • Note down the IP address shown
4. Authorize this Computer
  • The first time you connect, the TV will show an "Allow USB debugging?" popup
  • Check Always allow from this computer and press OK
