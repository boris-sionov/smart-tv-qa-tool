• Setup Developer Mode

    Do the following steps to get ready for setting up connection to your TV.

    1. Prepare Developer Account
    • You'll need a developer account to use Developer Mode
    • Go to webostv.developer.lge.com and create an LG developer account
    2. Install Developer Mode App
    • Open LG Content Store on your TV
    • Search for "Developer Mode"
    • Select Install
    3. Enable Developer Mode
    • Launch the Developer Mode app
    • Login with your developer account
    • Enable Developer Mode and wait for TV to restart
    4. Prepare for Device Setup
    • Launch the Developer Mode app again
    • Ensure Dev Mode Status is ON
    • Enable Key Server
    • Note down the device IP address and passphrase
